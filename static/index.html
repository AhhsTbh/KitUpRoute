🎮 PS5 setup

Do not change your PS5 DNS yet. The included DNS server listens only on localhost by default and cannot be reached by your console.

  1. Deploy a properly secured DNS service with a stable public IP.
  2. Test DNS resolution and authorized access from your home network.
  3. On PS5: Settings → Network → Settings → Set Up Internet Connection.
  4. Select your network → Advanced Settings → DNS Settings → Manual.
  5. Enter the deployed DNS IPs only after successful tests; restore Automatic DNS if connectivity fails.
